\section*{1. What I built and why}
A Go service on Groq's free tier (\code{qwen/qwen3.8-27b}) that answers only from the three papers, cites every sentence, and refuses rather than guess. Off-topic questions are refused with no model call; otherwise the model splits the question, then drafts, and a sentence is shown only if its cited passage holds every number in it. \textbf{The decision that shaped it:} tokens per minute are the scarce resource. Groq charges prompt + maximum reply up front against an 8,000-token bucket, so replies are capped and our own token-bucket limiter sits in front of Groq.

\section*{2. The real service and my stand-in}
34 calibration calls ($\le$3 a minute, on questions kept out of the scored set), including a deliberate probe that forced a real 429. Every header fits a bucket refilling at 133.3 tokens/s.

\section*{4. Where the time goes}
Slowest real answer (q18): 6,280\,ms, all \emph{working} (0 waiting, 0 retrying), all \emph{before} the first token. Re-ranking twice took 3,577\,ms (57\%); the first draft's sentence was dropped and redrafted. Source: per-step trace in \code{results/quality/}.

\section*{5. When a limit is hit}
\textbf{Per minute:} requests queue in order; one that would miss the 20\,s deadline is \emph{dropped} and gets the passages-only reply. The extra round is skipped (\emph{weaker answer}) when it can't fit. \textbf{Per day:} below 100 requests left, everyone gets a weaker one-call answer; at zero, a reply with no model call.

\section*{How this library will mislead a naive retriever}
\begin{enumerate}
\item \textbf{Common words win.} ``How many tokens was Helium pretrained on?'' returns ``4.2M tokens per step'', not ``2.1T''.
\item \textbf{No shared rare word.} ``How much data are H-Net's models trained on?'' never matches ``100B FineWeb-Edu''.
\item \textbf{Formulas break in PDF text.} ``h = 8'' (attention heads) ranked 27th under A.
\end{enumerate}

\section*{6. Retries}
Up to two retries, only if the deadline fits: on 5xx, stalls (no first token in 6\,s) and per-minute 429s; never on a daily 429. \textbf{Made it worse:} in the burst, two retries spent 9\,s on more 429s, then failed at 12.2\,s; no retry would have given the passages-only reply in $\sim$3\,s.

\section*{7. What the person sees}
Within $\sim$2\,s, no model call (exact text tested):
{\small\itshape ``I can't write an answer right now: today's model budget (1000 requests/day) is used up. It refills gradually, about one request every 1m26s: the next request can run in about 1m26s, and the full daily quota is back tomorrow at 15:00. The passages most likely to answer this are: \dots''}

\section*{8. What I'm unsure about, what I left out, what I learned}
\textbf{Least certain:} that a real citation holding every number means a right answer. gpt-oss broke it (``H100 GPUs [Moshi]'' for a Transformer question); if it fails, the system sends a cited wrong answer. I also chose R and qwen after seeing the scored run. \textbf{Not built:} real-Groq load tests (against its terms) and a vector database (376 chunks need none). \textbf{New to me:} a rate limit is a bucket, not a window: a refused call waits only until the bucket covers it (19.8\,s), not a full minute.
